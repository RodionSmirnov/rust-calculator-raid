# RUST RAID — калькулятор рейда для игры Rust

Python 3.10+, стандартная библиотека. Установка пакетов не требуется.

```sh
cd /workspace/rust-calculator-raid
python3 server.py --port 3000
```

Откройте http://localhost:3000 на своём компьютере. В облачной среде используйте доступ к порту, предоставляемый платформой. Остановка: Ctrl+C. `index.html` нельзя открывать отдельно: он использует Python API. HTML/CSS и небольшой JavaScript отвечают за браузерный интерфейс; все расчёты выполняет `calculator.py`.

## Возможности

Красно-чёрный интерфейс, двери и стены, несколько препятствий, количество, текущее HP, сторона стены, разбивка расхода, сера, порох и уголь. План сохраняется в localStorage браузера.

В каталоге есть взрывчатка (включая баллоны), огонь, патроны, стрелы, инструменты и ближний бой. Для ракет, C4, сачелей, бобовых гранат и разрывных патронов есть базовая таблица по целям с полным HP. Таблица не проверена для последнего патча, не является актуальной официальной базой игры.

Для остальных средств введите **фактический урон по конкретной цели за одну единицу**. Для пуль он зависит от оружия и расстояния, для инструментов — от материала и стороны. Смена стороны или оружия сбрасывает введённый урон. Для огня учитывайте полный цикл горения. Нулевой или неизвестный урон даёт «нет данных», а не нулевой расход. Для отсутствующего предмета используйте «Другое оружие / свой профиль». Каталог профилей не гарантирует, что каждый предмет способен повредить любую цель.

Можно указать серу всего и порох на 1 единицу расхода. Неизвестные рецепты показываются как «—». Сера уже включает серу для пороха. Уголь = порох × 3. Износ инструмента, ремонт, другие компоненты, возврат стрел и урон по площади не включены. Пользовательский урон применяется к каждой отдельной цели и округляется вверх; количество умножается после округления.

## Проверки

```sh
python3 -m unittest discover -v
```

API: `GET /api/catalog`, `POST /api/calculate`. Статические файлы ограничены белым списком; исходники сервера и Git-метаданные не раздаются.
