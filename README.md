# Калькулятор рейда Rust

Русскоязычный калькулятор для игры Rust. Двери и стены, несколько целей, ракеты, C4 и сачели; расчёт серы, пороха и угля. Без зависимостей и сборки.

Откройте `index.html` в браузере или запустите из корня:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Проверка расчётов: `node --test calculator.test.js`.

Значения для ванильной игры заданы в `calculator.js`. Расчёт предполагает полное здоровье каждой цели и отдельный расход на неё, без урона по области. Сера включает производство пороха; уголь указан для производства пороха. Другие компоненты не подсчитываются. Значения не сверены с текущим игровым патчем.
